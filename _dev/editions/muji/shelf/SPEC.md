# オーダー収納の見積り（idea・住空間）仕様

住空間メニューに「オーダー収納の見積り」を足す。ステンレスユニットシェルフ（SUS）の幅オーダー追加棚と、スタッキングシェルフのオーダーを、店頭でお客さまと一緒に見積もるための画面。

データは `shelf.json`（MUJIGRAM「15応対（生活雑貨）」の資料から作成）。価格・JANはここからだけ読む。コードに直接書かない。

## つなぎ方（IDEE と同じ形）
- `shelf/shelf.src.html`・`shelf/build_shelf.py` を作り、`build_muji.py` から `shelf.html` として一緒に公開する
- `muji.js`
  - `MENU.living` に `["shelf", IC.shelf, "オーダー収納の見積り", "SUSの棚板やスタッキングシェルフを、サイズを入れて金額まで"]` を追加（アイコンは棚の線画で新規）
  - `openSub` の `src` / `title` に `shelf` を追加
  - `closeSub` で `shelf` からも住空間メニューに戻る
- ヘッダーの戻る・`sub-ready` / `sub-close` の知らせ方は curtain・idee と同じ

## 画面1：どちらを見積もるか
「SUS 追加棚（幅オーダー）」「スタッキングシェルフ」の2択。

## 画面2A：SUS 追加棚（幅オーダー）
入力
1. 決め方：「置きたい場所の幅から」「中に入れたい物の幅から」「棚板の実寸で」
   - 場所の幅 → 脚の外〜外（①）として受け取り、棚板実寸＝入力−5.5
   - 物の幅 → 棚板の有効内寸（⑤）として受け取り、棚板実寸＝入力＋1
   - 実寸 → そのまま
   - 棚板実寸は1cm単位。小数は「収まる側」に丸める（場所の幅からなら切り捨て、物の幅からなら切り上げ）
   - 25〜81cm の外なら「オーダーできる範囲外」と表示
2. 材：オーク材／ウォールナット材
3. 帆立のサイズ：小／中／大／特大
4. 枚数（初期値1）

表示
- 決まった棚板実寸と、①脚 外〜外・②帆立 外〜外・③棚板（金具 外〜外）・⑤有効内寸（`dimensionOffsets` で計算）
- 追加棚：商品名・JAN・単価×枚数（`widthBands` から）
- クロスバー：種類（`crossbarTypeByWidth[実寸][帆立]`）と本数（`crossbarQtyByFrame[帆立]` × 枚数）、JAN・単価・「通常在庫品／受注品」
- 合計（税込）

## 画面2B：スタッキングシェルフ
入力
1. 幅：スリム／レギュラー／ワイド
2. 奥行：28.5cm／40cm
3. 材：オーク材／ウォールナット材
4. 高さ：「段数で選ぶ（1〜6段）」か「高さをオーダー（変則6段から2cm刻みで低く）」
5. 基本セット1台＋追加セットの台数（横に何列つなぐか）

表示
- 基本セット・追加セットそれぞれの商品名・JAN・単価・数量・配送サイズ（`stacking.items` から、order_type・size・set・tiers・wood・depth で引く）
- 全体の外寸：幅＝基本の幅＋追加の幅×台数、奥行、高さ
- 高さオーダーのときは「高さ ○○cm」を明記（239.5 から 2cm 刻みの値だけ選べる。下限は資料に無いので、とりあえず 42cm まで）
- 列数が5以上なら組立費 5,250円（税込）の行を出し「条件は店舗で確認」と添える
- 注意（`stacking.notes`）を下に小さく表示
- 合計（税込）

注意：レギュラー・ワイドの奥行28.5cm は、段数オーダーが 1・4・6段 だけ。選べない段数はボタンを押せなくする。

## 共通
- 「見積りをコピー」ボタン：品名・JAN・数量・金額・合計をテキストでコピー（カーテン見積と同じ書き方）
- 画面下に「価格は資料作成時点のものです。最新の価格は売場・ネットストアで確認してください」を常に表示
- スマホ縦画面が基本。文字・ボタンの大きさはカーテン見積に合わせる
- 文言を足したら `_dev/i18n-dict.json` に英語・韓国語も足す
