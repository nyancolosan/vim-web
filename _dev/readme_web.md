# VIM Web版 2.0

家具の配置を平面図と3Dで検討し、見積書・提案書まで作れるWebアプリです。Claudeの外で、どのブラウザでも動きます。

## 中身
| ファイル | 役割 |
|---|---|
| index.html | アプリ本体（これ1つで動きます） |
| manifest.webmanifest | ホーム画面に追加したときの名前・アイコン |
| sw.js | オフラインでも開けるようにする仕組み・更新の管理 |
| icon-180/192/512.png | アプリのアイコン |
| config.js | 課金サーバーのURLと表示料金の設定（サブスク開始時に書き換え） |
| tokushoho.html | 特定商取引法に基づく表記（【　】を書き換えて公開） |
| bimini-pt.js | 「写真のように仕上げる」用の計算部品（使うときだけ読み込みます） |

## 公開のしかた（いちばん簡単な方法）
1. Netlify Drop（https://app.netlify.com/drop）を開く
2. この `bimini-web` フォルダを、画面にドラッグ＆ドロップ
3. 数秒で `https://〇〇.netlify.app` のURLが発行されます（無料アカウントを作ると、URLを固定・変更できます）

ほかに Cloudflare Pages、GitHub Pages でも、フォルダをそのまま置くだけで動きます。
※ホーム画面への追加・オフライン利用には https のURLが必要です（上のサービスはすべて https です）。

## スマホのホーム画面に追加
- iPhone：Safariで開く → 共有ボタン →「ホーム画面に追加」
- Android：Chromeで開く → メニュー →「ホーム画面に追加」（または「アプリをインストール」）

## Claude版からのデータ移行
1. Claude版のVIMで「保存」タブ →「ファイルで持ち運ぶ」→「ファイルに書き出す」
2. Web版で「保存」タブ →「ファイルから読み込む」で、そのファイルを選ぶ

## 見た目の設定
右上の「設定」から、テーマカラー（10色＋自由な色）とフォント（無料フォント7種）を選べます。フォントはGoogle Fontsから読み込みます。

## Web版の違い
- AI機能（β版：AIレイアウト提案・写真から3D化・AIと話して3Dモデルをつくる）は表示されません
- 保存先は「その端末のブラウザ」です。端末をまたぐときは「ファイルに書き出す／読み込む」を使ってください
- 画像・PDF・ZIPの保存は通常のダウンロードになります
- 3D・平面図・展開図・見積書・提案書PDF・QRコードは、インターネット接続時に部品を読み込みます（一度開けば、オフラインでも使える場合があります）

## 更新のしかた
1. 新しい `index.html`（と `bimini-pt.js`）に差し替える
2. `sw.js` の1行目付近の `V="bimini-web-2.0.0"` の番号を上げる（例：2.0.1）
3. 同じ場所にもう一度アップロード
利用者は、開き直すだけで最新版になります。

## サブスク（PRO・販売員プラン）
`config.js` の `api` が空のあいだは、これまでどおり「PRO」ボタンで自由に切り替えられます。課金を始めるときは、同梱の `bimini-billing/README.md` の手順で課金サーバーを用意し、`api` にそのURLを入れてください。
